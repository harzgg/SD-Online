# COMICS PLUS! — HTML Shop Template

Static comics & games storefront for desktop testing.

**Brand:** COMICS PLUS!  
**Palette:** Yellow `#FFE600` · Gray `#6B7380` · White `#FFFFFF` · Blue `#1E7FE0`

## Quick start

1. Copy the entire `comics-plus` folder to your desktop.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Browse the shop, add items, and run through checkout.

No install or server required. The cart uses browser `localStorage`.

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Home / hero |
| `shop.html` | Full shop (filter, search, sort) |
| `comics.html` | Comics category |
| `games.html` | Games category |
| `product.html` | Product detail (`?id=...`) |
| `cart.html` | Cart |
| `checkout.html` | Checkout form |
| `success.html` | Order confirmation |
| `about.html` | Template info |

## Demo note

Checkout is a front-end simulation only — no real payments or orders.
