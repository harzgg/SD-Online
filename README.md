## What is SD-Online?

**SD-Online** is a community-made multiplayer platform for **SurrounDead**.

It is built to let players connect, play, and test shared PvE multiplayer systems while keeping the original survival experience at the center.

SD-Online includes:

- **SD-Online Player** — the main launcher/player app for joining SD-Online.
- **SDO Mod Studio** — a creator tool for making and publishing mods for the platform.
- **Server renting inside the launcher** — public and private server options are handled from the launcher’s **Purchase / Buy** section.

## Installation

1. Download the current SD-Online Player installer from the official website.
2. Run the installer and follow the setup prompts.
3. Make sure **SurrounDead is already installed through Steam**.
4. Open SD-Online and follow the launcher instructions.
5. Join the Discord if you need help or run into an issue.
